single_linkage.bend

uma fonte Bend

C nativo · clang compila para a CPU; chamadas paralelas usam threads

GPU · o mesmo arquivo C vira kernel CUDA (NVIDIA) ou Metal (Apple) para chamadas com !

JavaScript · executado com Bun, sequencialmente

bend file.bend -o file    # binário nativo
bend file.bend -o file.c  # fonte C
bend file.bend -o file.js # fonte JS
./file +RTS --threads 8 -RTS

A suíte de testes compila as seis entradas para C e JavaScript e exige saídas idênticas byte a byte. No run.py, --backend js pede --threads 1.
