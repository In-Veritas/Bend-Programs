Paralelismo fork-join por chamadas paralelas

def pow2(+n: Nat) -> U32:
  match n:
    case 0n:
      1
    case 1n+p:
      a b = pow2(p) pow2(p) # parallel call
      (a + b : U32)

def main() -> IO(Unit):
  IO.print(U32.show(pow2!(20n))) # `!` runs on GPU

a b = f(x) g(y)

f(x) em uma tarefa

g(y) em outra tarefa

junção: a e b prontos

As chamadas são independentes por construção (puro e afim); equilibrar a carga fica com quem programa. O agendador não migra tarefas.

No novo pipeline. pf_core.bend divide o trabalho do prefiltro e align.bend divide os pares entre tarefas. Os kernels históricos de agrupamento são seriais. JavaScript executa em sequência.
