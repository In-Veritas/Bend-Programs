def file_parse(fuel, file, stream, alphabet):
  match fuel:
    case Zero{}:
      stream_close_error(file, "input exceeds 256 MiB")
    case Succ{rest}:
      do IO<Result<String, Dataset>>:
        read: File & Result<(U32 & String), String> <- File.read(file, 65536)
        file_parse_read(read, stream, alphabet,
          handle => next => file_parse(rest, handle, next, alphabet))

Recursão só sobre partes menores, obtidas por match. Recursão mútua não existe.

Laços ligados ao mundo externo contam um Nat de combustível. Aqui, ele também é o limite de 256 MiB.

Um def @unsafe escapa da checagem, mas a verificação passa a imprimir SOME PROOFS FAIL.

Por que importa. Uma função que nunca retorna poderia provar qualquer coisa; exigir terminação mantém as provas sólidas.
